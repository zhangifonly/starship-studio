# Earth texture sources

- `earth-day.jpg`: NASA Visible Earth, The Blue Marble, downloaded September 6,
  2026 from https://eoimages.gsfc.nasa.gov/images/imagerecords/57000/57730/land_ocean_ice_8192.png
  and resized to 4096 px wide, JPEG quality 88, for browser delivery. Credit:
  NASA / Visible Earth. This is a composite basemap, not live satellite imagery.
- `earth-clouds.png`: distributed in Three.js r159 examples:
  https://raw.githubusercontent.com/mrdoob/three.js/r159/examples/textures/planets/earth_clouds_1024.png
- `earth-specular.jpg`: distributed in Three.js r159 examples:
  https://raw.githubusercontent.com/mrdoob/three.js/r159/examples/textures/planets/earth_specular_2048.jpg

The cloud and specular files are unchanged copies. Three.js repository license:
https://github.com/mrdoob/three.js/blob/r159/LICENSE . Repository provenance is
recorded here; no claim is made that the cloud map represents current weather.

Atmospheric rim, ocean waves, exhaust, smoke and splash are procedural Three.js
effects. Geographic imagery does not make the compressed illustrative trajectory
or vehicle-to-Earth scale physically accurate.
